# DEPLOY — установка на рабочий ПК

Проект поставляется **папкой с офлайн-установкой**. Сборка exe не используется:
приложение Windows-only, опирается на `tkinter`/`winreg`, и исходная схема
лаунчеров уже отлажена. На целевом ПК интернет не нужен.

Целевая машина: **Windows, Python 3.14.x**. Ожидается чистая установка —
существующие проезды не переносятся, база создаётся заново.

---

## 1. Подготовка на исходном ПК (есть интернет)

1. Убедитесь, что `requirements-lock.txt` согласован:

   ```bash
   python scripts/check_lock.py
   ```

2. Скачайте все колёса в `deploy/wheelhouse/`:

   ```bash
   python scripts/make_wheelhouse.py
   ```

   На выходе — 24 `.whl`-файла (~65 МБ). Папка в Git **не коммитится**.

3. Скопируйте **всю папку проекта** на целевой ПК, включая `deploy/wheelhouse/`.
   Исключите `.git/`, `data/logs/`, `__pycache__/`, `.pytest_cache/`.

   Если копируете через Git-клон — wheelhouse туда не попадёт, скопируйте его
   отдельно.

## 2. Установка на целевом ПК

1. Установите Python **3.14.x** с https://www.python.org/downloads/windows/
   (при установке отметьте «Add Python to PATH»).
2. Запустите `deploy\install.bat` двойным щелчком. Он:
   - проверит версию Python;
   - поставит все зависимости **из колёс без сети**
     (`pip install --no-index --find-links=deploy\wheelhouse`);
   - выполнит `pip check` и проверку импортов;
   - создаст `.env` из `.env.example`, если его ещё нет.
3. Проверьте окружение:

   ```bash
   python scripts/verify_install.py
   ```

   Ожидаемый вывод: Python 3.14, все модули импортируются, `pip check` зелёный,
   `.env` найден. Код возврата 0.

## 3. Настройка

1. Запустите `settings.bat`.
2. Заполните адрес камеры Dahua, логин/пароль, токен Telegram и ID чата.
3. Сохраните. Проверьте связь кнопкой проверки в окне настроек.

## 4. Запуск

1. `run.bat` — откроется окно «Эврика», сбор и сервис запустятся автоматически.
2. Для работы на постоянной основе включите автозапуск в настройках панели.

## 5. Проверка после запуска

```bash
python scripts/acceptance_check.py --skip-service
python scripts/verify_state.py
```

`acceptance_check` в первый день даст WARN «нет проездов» — это нормально,
пока камера не передала первый проезд. Блокирующих замечаний быть не должно.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `pip: no matching distribution` | wheelhouse собран под другую версию Python — пересоберите на исходном ПК с Python 3.14 |
| `ModuleNotFoundError` при запуске | перезапустите `deploy\install.bat` |
| Сервис не стартует | проверьте `.env` и `data/logs/service.stderr.log` |
| Панель не видит сервис | проверьте `127.0.0.1:18749` и `data/runtime/service.pid` |
| Автозапуск не работает после переноса папки | откройте `settings.bat` и включите автозапуск заново |

## Обновление уже установленной копии

1. Скачайте новую версию, сохранив `data/` и `.env`.
2. Запустите `deploy\install.bat` — он дотянет новые версии из wheelhouse.
3. Прогоните `python scripts/verify_install.py` и `scripts\local_ci.bat`.
